# Bloons Blitz Modding
A repo with my Bloons Blitz Modding tool and mods.

credits: anosu jitsu for the actual patcher.
I made the exe to go around the patcher to make it easier and the mod that is in this repo.


using this tool can sign you out of your bloons blitz account so make sure you are saving it with google play or an email first.

The releases section of this repo has the EXE tool and the dll mod and the code section has the source files for the mod.
Watch this video; LINK will go here when I have made the video, To see me doing these steps if you are confused the video also explains how you could make a mod for bloons blitz which isn't mentioned in this readme.

To use it download the exe file and any mods you want from the releases tab.
Hopefully I can add more mods later and you can use any mods you might find from other people.

Then create a folder named something related to bloons blitz modding and inside it create a Mods folder (capital M) the main folder can be named whatever 
and you can put it anywhere but the inside folder should be named exactly Mods.
Put any mods you have in the Mods Folder.


Then run the exe and press the Set Mods and References Directory button (it should be the only lit up one).
Now select your folder that you just created not the Mods folder but the one that the mods folder is directly inside of.

For example I made a folder name BloonsBlitzModdingReferences in my downloads folder with a Mods folder inside it when you do this the text on the window should update and the buttons should all light up.

Like this it shows I selected my folder with the Mods folder in it.

Next make sure your android device is connected to you PC via adb in other words connect your phone to your PC with a cable and make sure your phone has adb debugging enabled.
If you don't know how to enable debugging on your device look it up basically you have to turn on developer options and allow usbs to transfer files.

Now if this is your first time doing it or an update Has come out for Bloons Blitz that you want to have your mods on press run installer.
If you just want to update mods and have already installed mods on the newest update you can just press push mods without running installer
this will simply copy all files from your mods folder to the mods folder on your phone.
Pressing the push mods or pull references button when you have not press run installer yet will definitely cause an error.

When you press Run Installer the first thing it will do is i you already have the game installed it will uninstall it and open the play store where you need to press install.
Once it has installed press ok on the pop-up message.
The reason for this is to get the most recent official un-modded version of the game on your device to ensure you are modding the correct version.

Once you have pressed ok after it installed wait for it to say installer completed successfully if it outputs an error you can try to fix it or put an issue on this repo
or message me; https://discord.com/users/1121084969943584851

once it has installed open your game to the main menu an then close it and you can press push mods then.
